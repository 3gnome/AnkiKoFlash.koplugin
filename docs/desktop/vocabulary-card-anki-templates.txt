<script>
/* Style the part-of-speech labels (Noun, Verb, …) and grammar markers that
   dictionaries embed as plain text in the definition. Anki re-renders each
   card with a fresh DOM, so this runs cleanly every time. */
(function () {
  var el = document.getElementById("ankikoflash-def");
  if (!el) return;
  var POS = ["Proper noun", "Noun", "Verb", "Adjective", "Adverb", "Pronoun",
             "Preposition", "Conjunction", "Interjection", "Determiner",
             "Numeral", "Article", "Particle", "Prefix", "Suffix",
             "Abbreviation", "Contraction", "Symbol", "Phrase"];
  var html = el.innerHTML;
  POS.forEach(function (p) {
    var pat = p.replace(/ /g, "\\s+");
    var re = new RegExp("(^|[\\s>.;:,])(" + pat + ")\\b", "g");
    html = html.replace(re, '$1<span class="pos">$2</span>');
  });
  html = html.replace(
    /\(\s*(transitive|intransitive|obsolete|archaic|historical|figurative|literal|formal|informal|dated|rare|colloquial|slang)\s*\)/gi,
    '<span class="usage">($1)</span>');
  el.innerHTML = html;
})();
</script>
{{/Phrase}}

PART 5 — DECK (suggested)
================================================================================
Create deck:  English::Koreader

Plugin settings (on device):
  Settings → Card defaults → Vocabulary Card → Default deck
  Settings → Card defaults → Vocabulary Card → Note type: Vocabulary Card
  Optional: Preferred dictionary, One-tap send (Vocabulary)

Suggested deck-options preset:  Vocabulary Card

  New cards/day:              30–50
  Maximum reviews/day:        250
  Learning steps:             1m 10m 1d
  Graduating interval:        2 days
  Easy interval:              4 days
  Starting ease:              250%
  Bury related new/siblings:  OFF

Dictionary definitions are compact — slightly higher daily caps are often
comfortable.

Full setup guide (fields, plugin settings, dictionary install):
  docs/anki-vocabulary-card.md
