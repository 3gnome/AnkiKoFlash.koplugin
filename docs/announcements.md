## MobileRead — KOReader subforum (announcement thread)

**Forum:** https://www.mobileread.com/forums/forumdisplay.php?f=276
**Title:** `[Plugin] AnkiKoFlash — turn KOReader highlights into Anki cards (vocab + memorization)`

```
I built a KOReader plugin called AnkiKoFlash that turns reading into Anki flashcards
without leaving your book.

Long-press a word or highlight a passage, pick a card type, and it sends a
finished card to desktop Anki over Wi-Fi via AnkiConnect:

- Vocabulary Card: dictionary definition plus an offline etymology on the back.
- Memorization: LPCG-style overlapping step cards plus an optional full
  recitation card, great for poetry and prose.

Everything is configurable on the device (decks, note types, sync) — no SSH or
file editing on the Kobo. Optional auto-sync to AnkiWeb after sending. Works on
Kobo, Kindle (with KOReader), and the desktop emulator.

Repo + setup guide: LINK

Feedback and bug reports welcome — latest release: v1.2.0.

Optional companion for tags + Obsidian quote library:
```

## Reddit r/Anki

**Subreddit:** https://reddit.com/r/Anki
**Title:** `I read on an e-reader and build Anki cards from highlights via AnkiConnect`

```
I do most of my reading on an e-ink device and wanted my highlights to become
Anki cards automatically instead of copy-pasting later. So I wrote a KOReader
plugin (AnkiKoFlash) that does it over AnkiConnect.

Workflow: long-press a word or highlight a passage in KOReader → choose a card
type → it sends a finished card to desktop Anki on the same Wi-Fi.

Card types:
- Vocabulary Card: dictionary definition + the sentence it came from, plus an
  offline etymology section.
- Memorization: LPCG-style step cards + a full recitation card for poetry/prose,
  organized into Memorize::Book::page subdecks.

It auto-syncs to AnkiWeb after sending if you want, and all settings live on the
device.

It's free and open source (MIT): LINK

Happy to answer setup questions — you do need AnkiConnect running and a one-time
note-type setup, which the guide walks through.
```
