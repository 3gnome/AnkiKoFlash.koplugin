## Tips for capturing

- The desktop emulator is easiest for clean screenshots: `bash start.sh --emulator alice.epub`
- For a GIF on Windows, use ScreenToGif or ShareX; on macOS, Kap.
- Crop tightly and avoid showing any real API keys or your LAN IP.
- PNGs for stills, GIF (or MP4 linked separately) for the demo.

Once these files exist, commit them and the README images will appear.
